Sequencer C++ API¶

The native Projector integrates coordinated Strips into retained Sequence order and materializes their visible Projection. This reference is generated from the Doxygen documentation maintained beside every implementation unit in src/c++ and uses the concepts defined by src/VOCAB.md.
