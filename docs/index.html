    @sovereignbase/sequencer

    Sequencer

    Sequencer provides a deterministic total ordering for distributed data. It allows independently operating replicas to make concurrent changes and later converge on the same state without relying on network arrival order or perfectly synchronized clocks.

    Usage

    Simple typed API

    import { Projection } from '@sovereignbase/sequencer'

    const projection = new Projection<string>(1)
    const gossip = projection.insert(['Hello World'], 0)
    console.log(projection.value(0)) // "Hello World"

    projection.destroy()

    Compact data model

    An insertion contains six uint32 structural words: 24 bytes before transport framing or content. Numeric metadata accepts Uint32Array and JSON numeric arrays. Generic content, called Footage, stays in JavaScript; only numeric metadata enters WASM.

    sequence() returns [words, footage]: one numeric array and one content array, with no nested insertion or acknowledgement arrays. Small snapshots use six-word records after length-prefixed acknowledgements. From 64 retained insertions onward, predictable fields are omitted as WASM writes the snapshot; [0, frontiersEnd, insertionCount] identifies this compact numeric layout. Coordinates, acknowledgements and content order are preserved. The runtime reads both layouts; compact snapshots require an updated reader. Positive insertion lengths identify successive spans of footage. An empty Sequence is [[], []]. Construction and merge() accept numeric arrays or Uint32Array metadata; exported numeric arrays can be sent as JSON.

    const retained = projection.sequence()
    const restored = new Projection<string>(2, retained)

    Consecutive local insertions extend an intact insertion from the same Session without reserving another zero in its logical clock. Gossip contains only the new suffix, still using six structural words. A removal or fragmentation ends the local extension chain. Retained snapshots remain unchanged by later edits.

    Measured JSON transport sizes for 1,000 one-Frame insertions containing 'x', their removal Gossip, and a snapshot captured before removal:

    Gossip sizes include acknowledgements and content where present. Delta averages measure individual Gossip packets; batch totals include their enclosing array. Snapshot averages divide the complete Sequence size by the 1,000 authored insertions. Consecutive insertions are retained as one insertion. Sizes vary with Session IDs and content.

    Tests

    Behaviour guaranteed by excessive tests

    npm test rebuilds the native WebAssembly module and TypeScript package, typechecks tests, runs unit, convergence, integration and generative stress suites with V8 coverage, then runs runtime and browser compatibility checks.

    The latest verification passed 170 Vitest tests and 88 compatibility checks. The configured 100% coverage threshold remains unmet (95.66% statements, 94.94% branches, 100% functions, 97.23% lines). Convergence tests include 1,024 generated editing histories for each compaction mode. See the test suites and automated test report.

    Works everywhere where JavaScript and Wasm works

    Runtimes covered by the latest compatibility verification:

    • Node.js, ESM and CommonJS
    • Deno
    • Bun
    • Edge Runtime
    • Cloudflare Workers through workerd
    • Chromium and WebKit browser windows

    Firefox is also in the compatibility matrix; its matching Playwright browser binary was unavailable in the latest run.

    Tested realtime and offline text editing behaviour examples

    • Online and offline editors: six editors converge through delayed, reversed and shuffled delivery, including offline changes arriving during online editing.
    • Concurrent replacements: independent replacement histories retain the same surviving content across delivery orders.
    • Restart and redelivery: stored Sequences preserve visible content through hydration, duplicate delivery and further edits.
    • Peer-to-peer fanout: independently editing browser peers synchronize through BroadcastChannel.
    • WebSocket fanout: three browser peers converge through a stateless JSON Gossip relay.
