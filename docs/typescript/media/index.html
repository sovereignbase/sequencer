Methodology: avg µs/op is the arithmetic mean of the measured per-call latencies. Ops/sec is its reciprocal; displayed values are rounded as one reciprocal pair. Batch sizes only amortize timer overhead and are reported through call counts. These Node.js results do not represent browser runtimes.
